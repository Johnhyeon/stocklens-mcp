## 판정 기준 (러너가 종료코드에 반영)

1. **독립 재계산**: 1m 원천을 러너 내장 집계기(설계 14절 세션 명세로 독립
   구현)로 5/15/60/120/240m 재계산해 운영 결과와 전 버킷 비교. 불일치 = 실패.
   비교 가능한 완전 버킷이 없으면(장중 진행·저유동) 실패가 아니라
   `independent_compared=0` 기록 (완결일 재실행이 채움).
2. **KIS raw 교차** (비 KIS 공급자): 서버 리샘플을 거치지 않은 어댑터 원본끼리
   같은 날·종목 1m 대조. KR 은 타임스탬프 비대칭·OHLC 차이·거래량 비율
   |1-r|>0.01 전부 실패. 고정 예외 1개: provider 조회 시각에 형성 중이던
   분(end_at > 조회 시각)은 제외하고 `forming_excluded` 로 기록.
   US 는 거래소·테이프 기준 차이가 있어 관찰 기록.
3. **페이지네이션**: 실측 페이지 크기 기반 구조적 다페이지(pages >= 2) 요구.
   키움 KR 만 페이지 900행 > 하루 381행이라 별도 연속조회 probe(cont-yn/
   next-key 커서 진행)로 증명.
4. **캐시 2회차** (KR): 완료 거래일 2회차 조회가 cache_hit + 공급자 호출 0건
   (카운팅 프록시로 증명). 진행 중 거래일은 제품이 설계상 캐시하지 않으므로
   skip 으로 기록 (캐시 오염 방지).
5. **오류 분류**: 없는 종목 -> entity_not_found (신규 공급자 필수. KIS 는 0.9
   계약상 빈 결과 가능이라 관찰 기록), 잘못된 키 -> credential_invalid.
6. **auto 라우팅**: 게이트를 러너 프로세스 안에서만 연 미리보기
   (gate_preview=true)로 primary 공급자 선택 확인.
7. **primary 왕복**: 다른 공급자로 전환 후 복귀, 상태 파일 검증.
8. 보조 leg 실패도 종료코드에 반영된다. 게이트 flip 커밋은 해당 증거 커밋과
   짝을 이룬다.

## 실행 방법

```
STOCKLENS_HOME=D:\project\stocklens\.uat-home-1.0 \
  python docs/uat/evidence/common/uat_runner.py \
  --provider {kis|kiwoom|toss} --market {KR|US} --out docs/uat/evidence/<provider>
```

UAT 홈은 프로덕션(`~/.stocklens`, 0.9 v1 상태 그대로 보존)과 분리된
`D:\project\stocklens\.uat-home-1.0` (v2, 3사 연결). 증거 JSON 에 자격 증명·
계좌정보는 포함되지 않는다 (러너 sanitize + 커밋 전 검사).

## 실측으로 확정한 공급자 계약 (요약)

- **KIS US**: NYSE Arca 상장 ETF(SPY·IWM)는 EXCD=AMS 로만 조회된다 (NYS 는 빈
  결과). BRK.B 는 SYMB "BRK/B". 페이지 NREC 120.
- **키움 KR**: ka10080 페이지 900행, cntr_tm KST 봉 시작, 부호 가격, 없는
  종목 = return_code 0 + 빈 필드 행.
- **키움 US**: usa06011 의 cntr_tm 은 **ET 라벨(봉 시작)** 이다. 2026-08-27 의
  "계약 불일치" 판정은 KST 오독이 원인이었고(그 해석이 읽던 행 = 오버나이트
  ATS 체결), ET 해석은 lag 0 에서 KIS 와 완전 일치한다 (`kiwoom/
  us-contract-resolution-20260828.json`). strt_dt 는 ET 달력 D 앵커. 페이지
  100행. 없는 종목 = return_code 7 + 내부 코드 1903. 분봉 보존 3월까지 확인.
- **토스 US**: 실시간·완결일 타임스탬프는 정합하나 자체 테이프(전 분 OHLC
  상이, 거래량 10~40%), 과거 1분봉 보존 = 최근 2 거래 세션 + 각 주 금요일.

   업그레이드가 기존 구매자의 KIS 연결을 미검증으로 강등 -> 라우팅 차단.
   0.9 기록기로 재현하는 회귀 테스트 5종과 함께 수정 (e78119d).
2. **테스트의 실사용 캐시 오염**: STOCKLENS_HOME 미설정 테스트가 가짜 봉을
   실캐시에 기록 -> conftest 전역 격리 + 캐시 로더 날짜 검증 (7e7ee9c).
3. **키움 US cntr_tm 시간대 오독** (위 계약 참조, db51bab).
4. 판정기 자체 결함 다수 (커밋 이력 참조): 형성 중 분 규칙, 진행일 캐시 skip,
   compared=0 skip, 토큰 재시도 등.
