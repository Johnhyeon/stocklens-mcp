# StockLens 1.0 Multi-Broker Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship StockLens and LeetKit Manager 1.0.0 with secure, independently stored KIS, Kiwoom, and Toss market-data connections, one explicit primary broker, manual source switching, and verified Korean and US intraday bars.

**Architecture:** Replace KIS-specific connection and routing branches with a built-in Provider Registry, provider-scoped state and credentials, and a single primary-provider pointer. Every request pins one provider, normalizes one-minute bars into the existing `BarDataset`, and uses the existing session-safe resampler for higher intervals. Credentials remain in the OS keyring, broker endpoints are allowlisted, and disconnect is a two-phase disable-then-clean operation.

**Tech Stack:** Python 3.11+, asyncio, httpx, keyring, pytest, MCP, pywebview, vanilla JavaScript/CSS, uv, Git worktrees.
