## rc1 이후 달라진 것 (2026-09-11)

rc1 검증(2026-08-28) 뒤에 네이버 증권 화면이 개편되어 국내 도구가 전부
멈췄다. 그 수정을 rc1 위에 얹었으므로 **rc1 의 산출물 해시와 검증 증거는
이 릴리스에 그대로 쓸 수 없다.** 다시 빌드하고 다시 검증했다.

얹은 커밋 넷:

1. 네이버 구 화면 폐지 대응. 국내 도구 전부 JSON API 로 전환
2. 개인 순매매 열에 셋을 더해도 0이 아니라는 안내 추가
3. get_stock_sector 캐시 TTL 을 시세 기준으로 되돌림
4. 도구 66개를 실제로 한 번씩 불러보는 출시 점검기 추가

0.9.1 은 따로 내지 않기로 했다. 같은 날 1.0.0 이 나가므로 PyPI 에 버전을
둘 올릴 이유가 없고, 패치노트도 한 절로 합쳤다.

차트·지표)까지 확인했다. 단위 테스트는 응답을 흉내 내므로 원천이 사라진
것을 못 잡는다. 이번 사고 때 1,100개가 전부 초록이었던 이유가 그것이다.

## 남은 절차

아래 둘은 설치본과 실제 증권사 연결이 있어야 해서 개발 PC 에서 직접 돌린다.

1. `python docs/release/rc1_smoke.py --venv <venv경로>` — 설치본 스모크 16개
2. `python docs/release/rc1_single_broker.py --venv <venv경로>` — 단독 연결 흐름 8개

두 검증기를 연달아 돌리면 한국투자증권 토큰 발급 1분 1회 제한에 걸린다.
사이를 1분 이상 띄울 것.

그다음 두 저장소에 `v1.0.0` 태그를 민다. 태그 푸시가 곧 PyPI 공개다.
