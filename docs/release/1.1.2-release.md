## 담긴 것

- 세 Lens + Manager 공통: 고객 문구에서 터미널 명령·메일 주소를 빼고 Manager 버튼([활성화]·[구매]·[MCP 등록]·
  [업데이트]·[복구]·[텔레그램 로그인]·[지원 문의])으로 안내. 잠금 안내 4종은 세 Lens 가 Lens 이름만 빼고 같다
- 세 Lens 공통 진단: `RECENT_TOOL_FAILURES`(metrics 48시간, 오프라인), `_error_class.py` 원인 분류 9종(세 벌 동일,
  공개본 소스 sha256 앞 12자 `3c49bdb40d69`), `still_failing` — tls·dns·blocked·auth·schema 는 1번, other·timeout·connect 는
  같은 도구가 끝에서 연달아 2번 실패해야 warn. error_code 자리는 `details.error_code`
- StockLens
  - `stocklens_status` 가 만료·중지·날짜 되돌림 키를 "활성화됨"으로 보고하던 것(`license_block_reason` 로 판정)
  - `KR_DATA_REACHABLE` 6종 동시 확인(현재가·일봉·투자자 수급·시총 순위·테마·재무), `US_DATA_REACHABLE` 원인 분류,
    `BROKER_DATA_REACHABLE`(온라인, 연결·검증된 공급자 프로필별 분봉 1건, 연결 없으면 항목 없음)
  - 분봉 이름표를 받은 봉에서(끝난 거래일 `last_close`, 봉 0개면 요청 기준일), 키움 보관 기간 밖 날짜 `entity_not_found` 제거
  - 사건 반응·여러 종목 진단·투자자예탁금 기준일, 상세 수급 공급자 사유 보존·KIS 30거래일 coverage
  - 증권사 키 저장소 실패 `store_unavailable`/`key_missing` 분리, Manager·doctor 연결 슬롯 판정을 분봉과 같게
  - 활성화 창 사유 문구를 DartLens·TelegramLens 와 같게
- DartLens: DART 오류 XML 을 본문으로 읽지 않음·캐시 안 함, 수주잔고 원문 단위·보고서 기간 라벨, 실적 스캔 YoY 같은 기준·
  조회 실패 분리, KST 기간, 정정공시 검색 구간 잘림 표시, 대량보유·임원소유 coverage, 진단 012 IP 차단 문구
- TelegramLens: stock_buzz 무언급 라벨, 한글 통용명 해석 순서, 채널별 last_synced, baseline_ratio·timeline·velocity 이름표,
  결과 신선도·브리핑 KST, 트레이 메뉴 "LeetKit Manager 열기", 설치 정보 경고 고객 문구
- Manager: 진단 action 명령어 숨김(`looksLikeCommand`), LICENSE_ACTIVE revoked→지원 문의·clock→버튼 없음,
  [문제 해결] 주의 Lens 표시, 설치 실패·증권사 오류 버튼 이름, 새 진단 항목 이름표, 지원 문의 주소 `support@leetkey.kr`
