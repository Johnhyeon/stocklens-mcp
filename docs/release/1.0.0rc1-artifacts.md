## 이전 후보 (superseded, 사용 금지)

2026-08-28 첫 rc1 빌드의 **sdist 두 개**를 배포물 오염으로 폐기했다.
Manager sdist 에 과거 빌드 산출물 `dist_exe_new/LeetKitManager.exe`(19MB)와
테스트·내부 문서가, StockLens sdist 에 UAT 원본·설계 문서·프로토타입
이미지가 들어 있었다. 아래 해시를 가진 파일은 쓰지 않는다.

| 파일 | 폐기된 SHA-256 |
|---|---|
| `stocklens_mcp-1.0.0rc1.tar.gz` | `8716cb2f29461fda2d3229a505651db883507975d1e31c60dcd88a5ab1ea3518` |
| `leetkit_manager-1.0.0rc1.tar.gz` | `575e61d8b8e92c579f329692ac89a8f3c662e985406c6527d5aa022711159b16` |

**wheel 두 개는 바뀌지 않았다.** 오염은 sdist 제외 목록 문제였고 wheel 은
패키지 디렉터리만 담기 때문이다. 위 표의 wheel 해시는 첫 빌드와 동일하며
그대로 유효하다.

수정 내용: 두 pyproject 의 sdist 제외 목록 정비 (Manager 는 제외 설정
자체가 없었다). 결과 크기 Manager sdist 22.0MB -> 1.97MB,
StockLens sdist 0.64MB -> 0.42MB. 오염 후보 0건으로 재확인했다.

```
uv build            # 각 워크트리에서

```
